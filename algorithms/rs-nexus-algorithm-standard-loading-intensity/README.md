# Standard Loading Intensity Algorithm Plugin

Standalone RS Nexus algorithm plugin for `standard_loading_intensity`.

This plugin is a migrated copy of the built-in
`rs-nexus-os/rs_nexus_algorithms/standard_loading_intensity` implementation.
The built-in implementation remains unchanged and can continue to be used by
the current `rs-nexus-os` runtime until the isolated plugin runtime refactor is
complete.

## Development

Install the SDK and CLI from the local tooling repo, then build the wheel and
Phase 1 plugin bundle:

```bash
python -m build
rsnexus-plugin build --plugin-root . --output-dir build
```

For an offline-complete `.rsnxplugin`, include dependency wheels such as
`numpy` and `scipy` with repeated `--artifact` arguments.

## Notes

- Generated by `rsnexus-plugin init algorithm`
- Depends on `rs-nexus-plugin-sdk`
- Intermediate schedule: enabled
- Consolidation schedule: enabled
- Executor files are scaffolded for every algorithm. Runtime capability is declared by `plugin.json` and `config.yaml`.
- Requires `numpy` and `scipy` for signal processing.
- Algorithm entry point: `standard_loading_intensity.core:StandardLoadingIntensityAlgorithm`
- Intermediate executor entry point: `standard_loading_intensity.intermediate_executor:LoadingIntensityIntermediateExecutor`
- Consolidation executor entry point: `standard_loading_intensity.consolidation_executor:LoadingIntensityConsolidationExecutor`
